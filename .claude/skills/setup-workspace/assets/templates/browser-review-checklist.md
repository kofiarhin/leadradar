# Browser Review Checklist

For user-facing work, verify the actual flow when browser tooling is available.

- Desktop width
- Mobile width
- Loading state
- Empty state
- Validation/error state
- Success state
- Relevant keyboard/accessibility behaviour
- Console errors
- Network errors
- Buyer/user clarity against the current ticket and review standard

Report what was actually inspected. Do not mark unavailable checks as passed.
