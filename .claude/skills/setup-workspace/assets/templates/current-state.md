# Current State

## Proposed

List requested outcomes that are not yet implemented.

## Specified

List outcomes with an approved technical specification when supported.

## Planned

List outcomes with an approved implementation plan when supported.

## In Progress

List work currently being implemented when supported by repository/workflow evidence.

## Implemented

List behaviour that exists in the repository. Do not infer this from tickets, specs, or plans.

## Verified

List only checks and evidence actually run or inspected.

## Released

List only outcomes with evidence they reached the intended release environment. Otherwise use `Unresolved` or omit.

## Unresolved

List missing decisions, conflicts, risks, blocked work, and status uncertainty.
