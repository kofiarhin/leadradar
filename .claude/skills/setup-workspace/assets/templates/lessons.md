# Lessons

Use this file as lightweight persistent project memory.

Record only concise, repository-specific lessons supported by observed implementation, test, review, or debugging evidence. Do not add generic software advice, guesses, or rules copied from a ticket/spec/plan before the work proves them.

Prefer short entries grouped by relevant area, for example architecture, frontend, backend, testing, tooling, or product behaviour.

When a new lesson duplicates an existing one, refine the existing entry instead of adding noise. When a lesson becomes outdated, update or remove it only when current repository evidence clearly supersedes it.

If no implementation lessons have been observed yet, state: `No implementation lessons recorded yet.`
