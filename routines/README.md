# LeadRadar Routines

This directory is reserved for proposed recurring operator work. No routine or schedule is active as part of workspace setup.

For every proposed routine document:

- trigger/cadence;
- inputs and evidence sources;
- exact output;
- permitted writes/actions;
- limits and exclusions;
- failure/no-evidence behaviour.

Start with read-only or documentation-only routines such as a morning project brief or periodic verification/issue review. Do not activate code-changing, outreach, customer-data, GitHub-writing, deployment, or other external automation without a separate approved plan and the appropriate permission boundary.
